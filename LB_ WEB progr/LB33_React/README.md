# Лабораторна робота №33: Створення та запуск першого React-застосунку

## Виконані завдання:
1. **Ініціалізація проєкту:** Розгорнуто застосунок за допомогою утиліти Create React App (`npx create-react-app`).
2. **Структура React-проєкту:** Досліджено каталоги `src/`, `public/` та конфігураційний файл `package.json`.
3. **Створення компонента:** Розроблено базовий функціональний компонент у файлі `App.js`.
4. **Стилізація:** Налаштовано стилі у файлі `App.css`.
5. **Оптимізована збірка:** Перевірено формування продакшн-збірки командою `npm run build`.

## Як перевірити:
1. Відкрийте термінал у проєкті: `cd lb33-react`.
2. Запустіть сервер: `npm start`.
3. Відкрийте у браузері `http://localhost:3000`.
