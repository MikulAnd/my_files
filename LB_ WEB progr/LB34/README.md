# Лабораторна робота №34: React — концепція компонентів і декларативного підходу

## Виконані завдання:
1. **Створення функціонального компонента:** Реалізовано компонент `MyName` для відображення імені студента.
2. **Композиція компонентів:** Розроблено компоненти `CourseTitle` (назва курсу) та `CourseTopics` (перелік тем).
3. **Об'єднання в головному інтерфейсі:** Зібрано всі компоненти всередині головного компонента `App`.
4. **Стилізація інтерфейсу:** Застосовано CSS-стилі для списку тем та інформаційних карток.

## Як перевірити:
1. Відкрити термінал у застосунку: `cd lb33-react`.
2. Запустити локальний сервер: `npm start`.
3. Перевірити відображення сторінки: `http://localhost:3000`.
