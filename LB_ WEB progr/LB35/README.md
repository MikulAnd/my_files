# Лабораторна робота №35: Створення першого компонента: функціональні та класові компоненти

## Виконані завдання:
1. **Функціональний компонент з Props:** Створено компонент `UserInfo`, який приймає властивості `name` та `age`.
2. **Класовий компонент зі State:** Реалізовано компонент `Counter` з внутрішнім станом та методом збільшення значення за кліком.
3. **Додаткове завдання:** Реалізовано управління списком студентів через класовий компонент `StudentList` та виведення окремих записів через функціональний `StudentItem`.

## Запуск:
1. `cd lb33-react`
2. `npm start`
3. Перевірити відображення сторінки: `http://localhost:3000`.
