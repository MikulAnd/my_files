# Лабораторна робота №38: Життєвий цикл класових компонентів

## Виконані завдання:
1. **Завдання 1 (Таймер):** Реалізовано запуск інтервалу в `componentDidMount` та його очищення у `componentWillUnmount`.
2. **Завдання 2 (API Fetcher):** Реалізовано асинхронний запит до JSONPlaceholder всередині `componentDidMount` для завантаження користувачів.
3. **Завдання 3 (Спостереження за розмонтуванням):** Реалізовано приховування компонента `Child` із виведенням повідомлення у консоль під час виклику `componentWillUnmount`.
