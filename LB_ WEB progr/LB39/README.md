# Лабораторна робота №39: React Hooks (useState, useEffect, useMemo, useCallback)

## Виконані завдання:
1. **useState:** Реалізовано компонент введення тексту та підрахунку символів `TextCounter`.
2. **useEffect:** Реалізовано асинхронне завантаження користувачів у таблицю через `UsersList`.
3. **useMemo:** Оптимізовано обчислення суми елементів масиву в `SumCalculator`.
4. **useCallback:** Мемоізовано передачу функції `handleClick` у дочірній компонент `ChildButton`.

## Запуск:
1. `cd lb33-react`
2. `npm start`
