# Лабораторна робота №40: Робота з формами: керовані та некеровані компоненти

## Виконані завдання:
1. **Керовані компоненти:** Реалізовано форму реєстрації з контролем значень полів через `useState`.
2. **Некеровані компоненти:** Отримання значень полів без синхронізації зі станом напряму через `useRef`.
3. **Багатопольова форма:** Організовано форму з кількома полями на основі єдиного об'єкта стану `formData` та динамічного обробника `[name]: value`.
4. **Валідація форми:** Додано клієнтську перевірку заповнення обов'язкових полів і коректності формату email з виведенням повідомлень про помилки.

## Запуск:
1. `cd lb33-react`
2. `npm start`
