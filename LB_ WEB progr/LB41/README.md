# Лабораторна робота №41: Основи Redux: store, action, reducer

## Виконані завдання:
1. **Інсталяція:** Встановлено бібліотеки `redux` та `react-redux`.
2. **Store & Reducer:** Створено центральне сховище та чистий `itemReducer` для обробки подій.
3. **Actions:** Описано творці дій `addItem` та `removeItem`.
4. **Підключення через Provider:** Додаток обгорнуто у `<Provider store={store}>` на кореневому рівні.
5. **Робота з хуками:** Реалізовано читання стану за допомогою `useSelector` та відправку дій через `useDispatch`.

## Запуск:
1. `cd lb33-react`
2. `npm start`
