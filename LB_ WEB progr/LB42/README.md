# Лабораторна робота №42: Налаштування Redux та налагодження за допомогою DevTools

## Виконані завдання:
1. **Архітектура проєкту:** Створено структуру каталогів `/store` та `/components`.
2. **Логіка стану:** Описано дії `increment`, `decrement`, `reset` та редюсер `counterReducer`.
3. **Налаштування DevTools:** Підключено розширення Redux DevTools через compose/window hook у `store.js`.
4. **Компонент Counter:** Реалізовано відображення значення через `useSelector` та виклик подій через `useDispatch`.
5. **Time-travel debugging:** Перевірено історію дій (Actions), відстеження змін (Diff) та повернення стану у минуле через Redux DevTools.

## Запуск:
1. `cd lb33-react`
2. `npm start`
