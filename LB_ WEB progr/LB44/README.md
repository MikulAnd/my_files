# Лабораторна робота №44: Визначення дій (Actions) для управління станом

## Виконані завдання:
1. **Список покупок:** Оголошено константи `ADD_PRODUCT`, `REMOVE_PRODUCT`, `UPDATE_QUANTITY` та реалізовано action creators.
2. **Управління користувачами:** Створено генератори дій для операцій `ADD_USER`, `REMOVE_USER`, `UPDATE_USER`.
3. **Todo-список (Додаткове завдання):** Описано константи та генератори `addTodo`, `removeTodo`, `toggleTodo`, `editTodo`.
4. **Інтерактивна перевірка:** Створено інтерфейс для генерації дій та виведення сформованих action-об'єктів на екран і в консоль.

## Як запустити:
1. `cd lb33-react`
2. `npm start`
