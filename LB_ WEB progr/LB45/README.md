# Лабораторна робота: Todo-додаток на Recoil

## Виконані завдання:
1. **Ініціалізація Recoil:** Підключено `<RecoilRoot>` у файлі `index.js`.
2. **Створення Atoms (`atoms.js`):** Налаштовано глобальні стани для масиву завдань (`todoListState`) та фільтра (`todoFilterState`).
3. **Створення Selectors (`selectors.js`):** Реалізовано обчислення залишкових завдань (`incompleteCount`) та фільтрацію списку на льоту (`filteredTodoListState`).
4. **Компоненти (в `App.js`):** 
   - `AddTodo`: Форма додавання з читанням/записом через `useRecoilState`.
   - `TodoFilters`: Вкладки фільтрів та кнопка очищення виконаних.
   - `TodoList`: Виведення відфільтрованого списку через `useRecoilValue`, перемикання статусів та видалення окремих завдань.

## Примітка щодо запуску:
Усі вихідні файли цієї роботи збережено у поточній директорії. Оскільки в рамках курсу використовується єдиний робочий проєкт (пісочниця), код у ньому регулярно оновлюється під нові завдання. 

**Щоб перевірити саме цю роботу локально:**
1. Скопіюйте всі файли з цієї папки (`App.js`, `App.css`, `atoms.js`, `selectors.js` тощо) у папку `src/` будь-якого розгорнутого React-проєкту.
2. Встановіть необхідну залежність:
   ```bash
   npm install recoil
